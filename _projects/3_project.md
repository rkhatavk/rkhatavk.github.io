The project incorporated an electronic locking feature into an existing open differential while making the fewest possible changes to the original assembly, culminating in a functional prototype.

We developed an innovative arrangement in which the electromagnetic actuator and locking mechanism were mounted on opposite sides of the ring gear. This configuration enabled the modified differential-case assembly to fit within the existing compact carrier and axle housing.
